# dsh-preset-menu

把新建任务页的 **Agent 模式弹窗**做成真正的锚定弹层：

- **默认向下**展开；下方挤不出位置、上方更宽裕时才改为上浮；
- 高度封在按钮下方的可用空间上，顶到窗口下沿留 `bottomInset` 的位置收口，内容更多就在列表内滚动（不画滚动条，滚轮 / 触控板照常翻）；
- 行内「名称 + 描述」重新排版（名称半粗、描述次级色），勾选与名称对齐；
- 面板与行比官方圆角档位各多 4px，边角更软；
- 底色、阴影、描边一律沿用官方菜单样式，不改配色；
- 结构认不出来时**不动手**，保留官方行为。

## 可调参数

**方式一（推荐）**：设置 → **模式弹窗**。四个数字直接改，点「保存」即写回插件目录下的 `preset-menu.json`，下次点开模式菜单生效。

**方式二**：直接编辑 `preset-menu.json`：

```json
{
  "bottomInset": 12,
  "sideGap": 8,
  "panelWidth": 368,
  "minSpace": 96
}
```

| 字段 | 含义 | 默认 | 允许范围 |
| --- | --- | --- | --- |
| `bottomInset` | 面板底边距窗口下沿的像素，**越小面板向下伸得越低** | 12 | 0–200 |
| `sideGap` | 面板与模式按钮之间的间距 | 8 | 0–64 |
| `panelWidth` | 面板宽度 | 368 | 220–900 |
| `minSpace` | 下方不足这个高度就改为上浮 | 96 | 0–800 |

两条路走的是同一个宿主路由 `/dsh-preset-menu/config`（GET 读、POST 写，每次请求都重读文件），所以改完保存即可生效，不用重启。写错或删掉文件也不影响使用：会退回内置默认值，越界数字自动夹回允许范围。

## 组成

| 文件 | 角色 |
| --- | --- |
| `index.js` | 宿主半区：`/dsh-preset-menu/config`（GET 读 / POST 写），每次请求重读 `preset-menu.json` 并夹紧越界值 |
| `client.js` | 浏览器半区：注入样式 + 监听弹窗挂载 + 计算方向/坐标/限高；并在 设置 → 模式弹窗 提供调参页 |
| `cordis.patch.yml` | 挂载宿主行 |
| `preset-menu.json` | 外部可调的几何参数 |
| `locale/{zh,en}.json` | 插件管理器里的标题与描述 |
| `docs/DETAIL.md` | 插件详情页文档 |
| `icon.svg` | 插件图标 |

## 为什么不改官方组件

弹窗属于 `@deepseek-ai/dsh-client-ui-agent-preset` 渲染的 primitives `<Menu>`，
没有可供外部替换的插槽。这里以「结构指纹」识别它：`role="menu"` 面板里至少两行
是「名称 + 描述」的两段 `span`。官方改结构时最多是退化成原行为，不会报错。

## 坐标：为什么要两次采样

桌面端窗口可能处在带 CSS `zoom` 的祖先里，此时 `style.top/left` 会被缩放，直接
把 `getBoundingClientRect()` 的渲染坐标写回去会按比例漂出窗口。`fitAxis()` 采两次
样解出「渲染值 = 比例 × 写入值 + 偏移」，再反解写入值，缩放不为 1 时也能落位。

## 安装

DSH 里通过插件管理器的「添加插件」选择本目录，或由 agent 用 `plugin_manager`
`install_bundle` 安装。安装后刷新页面生效；卸载即恢复原样。
